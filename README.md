# NET25: Valfri arkitektur

> Ange den valdra arkitekturen här och en kort beskrivning över vad programmet gör.

Projektet använder MVVM tillsammans med Windows Presentation Foundation(wpf), programmet hjälper en hitta de rune ordern man kan skapa om man har många runor i spelet Doomdepths.

## Doomdepths - Runewords helper

<img width="200" align="right" height="auto" alt="bild" src="https://github.com/user-attachments/assets/cfcb3efa-c422-4a59-8ffd-cffce67ce77f"/>

Doomdepths är ett turbaserat roguelike-rollspel som jag har spelat länge nu.

Inuti spelet så finns det 20 unika runor som man kan tillsätta på vapen för att få olika effekter. Som du kan se på bilden nere i hörnet så har jag bara 8 runor där men man kan få många mer om man har tur.

Totalt så finns det 27 olika "Runewords" som man kan skapa där 15 av dem kräver 3 runor och 12 av dem kräver 2 runor, som du kan tänka dig så kan det vara svårt att hitta vilka runewords som man kan skapa. 

Även där på så är webbsidan med alla runewords full av reklam och popups så att man inte ens kan se något där.

Det är därför jag har skapat ett simple program där man kan klicka i de runorna som man har och de runewords som man kan skapa dyker då upp bredvid.
